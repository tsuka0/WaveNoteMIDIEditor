# WaveNote MIDI Editor 
ダウンロードは[こちらから](https://github.com/tsuka0/WaveNoteMIDIEditor/releases/latest)!!

音声ファイルのスペクトラムを確認しながら、MIDIを作成・編集できる Windows 向けピアノロールエディタです。  
音声とMIDIを同じタイムラインで扱えるため、耳と視覚の両方を使ってノートを調整できます。  

## 主な機能

- WAV / MP3 / FLAC / OGG / M4A の読み込み
- CQTベースのスペクトラム表示
  - 表示の閾値・感度をリアルタイムに調整
  - 音声オフセットと連動して表示
- 音声からのテンポ推定
  - MIDIファイル未読込時のみ実行
  - 推定テンポをグリッドとテンポ入力欄に反映
  - 音声オフセットは自動変更しません
- MIDIの作成・読み込み・保存 (`.mid` / `.midi`)
- ノートの追加、移動、リサイズ、コピー＆ペースト、削除
- ベロシティ編集、サステインペダル (CC64) の編集
- テンポ・拍子の変更および再生位置への追加
- 元に戻す / やり直し
- 内蔵音源または Windows MIDI出力デバイスでの再生
- プロジェクト保存・読み込み (`.wnp`, gzip圧縮)

## 動作環境

- Windows 10 / 11
- Python 3.10 以降
- MIDI出力はWindowsのwinmm APIを使用します。

## 基本的な使い方

1. **ファイル → オーディオを開く** から音声を読み込みます。
2. MIDIをまだ読み込んでいなければ、テンポと拍位置を自動推定します。推定値は目安として確認してください。
3. 必要に応じて、ツールバーでテンポ、拍子、音声オフセット、スペクトラムの閾値・感度を調整します。
4. ピアノロール上でノートを追加・編集します。
5. **ファイル → MIDIを保存** で書き出します。作業を続ける場合は `.wnp` プロジェクトとして保存してください。

### 音声とグリッドを合わせる
テンポ解析は一定テンポの楽曲で特に有効です。生演奏、テンポ変化、無音の長いイントロ、複雑なリズムでは推定結果がずれる場合があります。
音声の開始位置は自動では移動しません。スペクトラムとグリッドを手動で合わせるには、ツールバーの **音声オフセット** を調整するか、ピアノロール上で `Alt` を押しながらドラッグしてください。
MIDIファイルを読み込んだ場合は、そのMIDIに含まれるテンポ情報を優先するため、音声のテンポ解析は実行しません。

## 操作

### ショートカット
| 操作 | 内容 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `Shift` + `Space` | テンポ計測(精度低) |
| `S` | ノートを再生位置で分割 (選択時は選択中のノートのみ) |
| `Ctrl` + `N` | プロジェクトを新規作成 |
| `Ctrl` + `O` | プロジェクトを開く |
| `Ctrl` + `S` | プロジェクト保存 |
| `Shift` + `S` | MIDI上書き保存 |
| `Ctrl` + `Z` / `Ctrl` + `Y` | 元に戻す / やり直し |
| `Ctrl` + `C` / `Ctrl` + `X` / `Ctrl` + `V` | ノートのコピー / 切り取り / 貼り付け (貼り付け位置は再生位置・グリッドスナップ) |
| `Ctrl` + `A` | すべて選択 (全トラック表示時は全ノート、トラック選択時はそのトラック) |
| `Delete` / `Backspace` | 選択ノートを削除 |
| 矢印キー | 選択ノートを移動 (左右=1グリッド、上下=半音) |
| `Shift` + 矢印キー | 選択ノートを大きく移動 (左右=4グリッド、上下=1オクターブ) |

### ノート編集
| 操作 | 内容 |
| --- | --- |
| 左クリック (空き部分) | ノートを追加 (ドラッグで長さを調整) ※トラック選択時のみ |
| 左ドラッグ | ノートの移動 (複数選択時はまとめて移動) |
| ノート右端をドラッグ | 長さの変更 |
| `Ctrl` + ドラッグ | ノートの複製 |
| ダブルクリック | ノートの削除 |
| 右ドラッグ | 範囲選択 |
| 右クリック | コンテキストメニュー (ベロシティ設定 / ノーツを結合 / コピー / 切り取り / 削除 / オクターブ上・下) |

### ベロシティ・ペダル
| 操作 | 内容 |
| --- | --- |
| ベロシティレーン 左ドラッグ | ドラッグした範囲のベロシティを編集 |
| ベロシティレーン 右ドラッグ | 選択範囲になじませるようにベロシティを変化 |
| ベロシティバー ダブルクリック | ベロシティを数値で入力 |
| ペダルレーン クリック | サステインペダル (CC64) の挿入・移動 |

### 再生・表示
| 操作 | 内容 |
| --- | --- |
| 上部タイムライン クリック | 再生位置を移動 (グリッドにスナップ) |
| 下端のスクラブバー ドラッグ | 再生位置をスクラブ |
| ホイール | 縦スクロール |
| `Ctrl` + ホイール | 拡大 / 縮小 (鍵盤上ではノートの高さ変更) |
| `Shift` + ホイール | 横スクロール |
| 中ボタン ドラッグ | 横方向にパン |
| 鍵盤クリック | 音をプレビュー |
| テンポ・拍子マーカー ダブルクリック | マーカーの編集ダイアログを開く |

### その他
| 操作 | 内容 |
| --- | --- |
| `Alt` + ドラッグ | 音声オフセットを調整 |
| `Alt` + ホイール | トラック切り替え |
| トラックのドロップダウンを右クリック | トラック名の変更 |
| ツールバー「テンポ追加」「拍子追加」 | 再生位置にテンポ・拍子を挿入 |

※ 設定メニューから「設定...」を開き、「ショートカット」タブから主要なショートカットキーをカスタマイズできます。

## 注意事項
- テンポ解析は補助機能です。正確な編集の前にグリッド位置を確認してください。
- 外部MIDIデバイスの利用可否は、Windows側で認識されているデバイスに依存します。
- プロジェクトに保存される音声ファイルはパス参照です。音声ファイルを移動・削除すると、プロジェクトから読み込みできなくなります。

## ファイル形式
| 種類 | 拡張子 | 説明 |
| --- | --- | --- |
| 音声 | `.wav`, `.mp3`, `.flac`, `.ogg`, `.m4a` | 解析・再生用の音声ファイル |
| MIDI | `.mid`, `.midi` | 読み込み・書き出し可能なMIDIファイル |
| プロジェクト | `.wnp` | gzip圧縮されたJSON。MIDI、テンポ、拍子、音声パス、表示・再生設定を保存 (従来の非圧縮ファイルも読み込み可能) |

## プロジェクト構成

| ファイル | 役割 |
| --- | --- |
| `main.py` | アプリケーション本体、メニュー、ツールバー、ファイル操作 |
| `module/piano_roll.py` | ピアノロール描画・編集、グリッド・スペクトラム表示 |
| `module/audio.py` | 音声読み込み、再生、内蔵音源レンダリング |
| `module/spectrum.py` | CQTスペクトラムとテンポ・拍位置解析 |
| `module/midi.py` | MIDIデータ、テンポ・拍子モデル、入出力、編集履歴 |
| `module/midiout.py` | Windows MIDI出力デバイスの列挙・送信 |
| `module/settings.py` | アプリケーション設定の保存・読み込み |
| `module/discord_rpc.py` | Discord Rich Presence 通信機能 |

## Discord Rich Presence
設定から Discord Rich Presence を有効にすると、Discordのプロフィールに「WaveNoteMIDIEditor」をプレイ中であることを表示できます。
