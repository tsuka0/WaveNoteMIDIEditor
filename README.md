# WaveNote MIDI Editor

音声ファイルのスペクトラムを確認しながら、MIDIを作成・編集できる Windows 向けピアノロールエディタです。音声とMIDIを同じタイムラインで扱えるため、耳と視覚の両方を使ってノートを調整できます。

## 主な機能

- WAV / MP3 / FLAC / OGG / M4A の読み込み
- CQTベースのスペクトラム表示
  - 表示の閾値・感度をリアルタイムに調整
  - 音声オフセットと連動して表示
- 音声からのテンポ推定
  - MIDIファイル未読込時のみ実行
  - 推定テンポをグリッドとテンポ入力欄へ反映
  - 音声オフセットは自動変更しません
- MIDIの作成・読み込み・保存（`.mid` / `.midi`）
- ノートの追加、移動、リサイズ、コピー＆ペースト、削除
- ベロシティ編集とサステインペダル（CC64）編集
- テンポ・拍子の変更および再生位置への追加
- 元に戻す / やり直し
- 内蔵音源またはWindows MIDI出力デバイスでの再生
- プロジェクト保存・読み込み（`.wnp`）

## 動作環境

- Windows 10 / 11
- Python 3.10 以降
- MIDI出力はWindowsのwinmm APIを使用します

## インストール
基本はリリースからexeファイルをダウンロードして使用してください。  
以下はコードをダウンロードして使う方法です。  

PowerShellでプロジェクトのフォルダーを開き、次を実行します。

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 起動

```powershell
python main.py
```

## 基本的な使い方

1. **ファイル → オーディオを開く** から音声を読み込みます。
2. MIDIをまだ読み込んでいなければ、テンポと拍位置を自動推定します。推定値は目安として確認してください。
3. 必要に応じて、ツールバーでテンポ、拍子、音声オフセット、スペクトラムの閾値・感度を調整します。
4. ピアノロール上でノートを追加・編集します。
5. **ファイル → MIDIを保存** で書き出します。作業を続ける場合は `.wnp` プロジェクトとして保存してください。

### 音声とグリッドを合わせる

テンポ解析は一定テンポの楽曲で特に有効です。生演奏、テンポ変化、無音の長いイントロ、複雑なリズムでは推定結果がずれる場合があります。

音声の開始位置は自動では移動しません。スペクトラムとグリッドを手動で合わせるには、ツールバーの **音声オフセット** を調整するか、ピアノロール上で `Alt` を押しながらドラッグしてください。

MIDIファイルを読み込んだ後は、そのMIDIに含まれるテンポ情報を優先するため、音声のテンポ解析は実行しません。

## 操作

| 操作 | 内容 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `Shift` + `Space` | テンポ計測(精度低) |
| `Ctrl` + `S` | プロジェクト保存 |
| `Ctrl` + `N` | 新規MIDI |
| `Ctrl` + `Z` / `Ctrl` + `Y` | 元に戻す / やり直し |
| `Ctrl` + `C` / `Ctrl` + `X` / `Ctrl` + `V` | ノートのコピー / 切り取り / 貼り付け |
| `Delete` / `Backspace` | 選択ノートを削除 |
| 矢印キー | 選択ノートを移動 |
| `Alt` + ドラッグ | 音声オフセットを調整 |

## ファイル形式

| 種類 | 拡張子 | 説明 |
| --- | --- | --- |
| 音声 | `.wav`, `.mp3`, `.flac`, `.ogg`, `.m4a` | 解析・再生用の音声ファイル |
| MIDI | `.mid`, `.midi` | 読み込み・書き出し可能なMIDIファイル |
| プロジェクト | `.wnp` | MIDI、テンポ、拍子、音声パス、表示・再生設定を保存 |

## プロジェクト構成

| ファイル | 役割 |
| --- | --- |
| `main.py` | アプリケーション本体、メニュー、ツールバー、ファイル操作 |
| `piano_roll.py` | ピアノロール描画・編集・グリッド・スペクトラム表示 |
| `audio.py` | 音声読み込み、再生、内蔵音源レンダリング |
| `spectrum.py` | CQTスペクトラムとテンポ・拍位置解析 |
| `midi.py` | MIDIデータ、テンポ・拍子マップ、入出力、編集履歴 |
| `midiout.py` | Windows MIDI出力デバイスの列挙・送信 |
| `settings.py` | アプリケーション設定の保存・読み込み |

## 注意事項

- テンポ解析は補助機能です。正確な編集前にグリッド位置を確認してください。
- 外部MIDIデバイスの利用可否は、Windows側で認識されているデバイスに依存します。
- プロジェクトに保存される音声ファイルはパス参照です。音声ファイルを移動・削除すると、プロジェクトから再読み込みできなくなります。
